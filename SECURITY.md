# Security policy

## Reporting a vulnerability

Please report security problems privately by email to security@encylia.com. Don't open a public issue for a security problem.

Include what you found, how to reproduce it, and which version or commit you were running. You'll get an acknowledgment within 7 days, and we'll keep you updated until it's fixed.

## Supported versions

SSVS is in planning and has no releases yet. Once releases begin, this section will list which versions receive security fixes.

## For organizations running SSVS

Security fixes are called out in the release notes. Watch the repository's releases so you know when to update your install.
